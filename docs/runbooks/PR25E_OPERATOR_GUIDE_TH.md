# คู่มือเจ้าหน้าที่ Pool: การทำงานเมื่อเซิร์ฟเวอร์ไม่พร้อม (ออฟไลน์)

**Purpose:** คู่มือสั้นสำหรับเจ้าหน้าที่ Equipment Pool ที่ใช้โหมดออฟไลน์ (PR25E)
**Authority:** อธิบายพฤติกรรมที่สร้างจริงใน PR25E; ที่มาและเหตุผล: `docs/design/PR25D_OFFLINE_OPERATION_PLAN.md`; สัญญา API: `docs/api/sync.md`
**Update trigger:** พฤติกรรมหน้าจอออฟไลน์เปลี่ยน
**Maintainer:** Documentation/Governance Engineer

คู่มือสำหรับผู้ตรวจสอบรายการ: `docs/runbooks/PR25E_REVIEWER_GUIDE_TH.md`
ข้อจำกัดที่ทราบ: `docs/KNOWN_LIMITATIONS.md`

## 1. หลักการ

เมื่อเซิร์ฟเวอร์ของหน่วยงานดับหรือเชื่อมต่อไม่ได้ ท่านยังบันทึก **เบิก (dispatch)** และ **รับคืน (receipt)** ได้ รายการจะเก็บในเครื่องที่ใช้อยู่ แล้วส่งเข้าระบบเองเมื่อเชื่อมต่อได้ ไม่ต้องกดส่ง การทำงานปกติ (ออนไลน์) ไม่เปลี่ยน

ต้องเปิดแอปจากเครื่องนี้และเข้าสู่ระบบ **ขณะออนไลน์อย่างน้อยหนึ่งครั้ง** ก่อน ระบบไม่รองรับการล็อกอินขณะออฟไลน์

## 2. ทำอะไรได้ / ไม่ได้ขณะออฟไลน์

| ทำได้ | ทำไม่ได้ (ต้องออนไลน์) |
|---|---|
| ค้นหาเครื่องด้วย **รหัส BCM** (จากข้อมูลที่เก็บไว้ในเครื่อง) | **สแกน QR** (ใช้ได้เฉพาะออนไลน์) |
| บันทึกเบิก (เลือกหอ/หน่วยงาน เบอร์โทรเติมให้ตามหอ แก้ได้) | รายงาน ประวัติ ค้นหาด้วย Item No / Asset Number |
| บันทึกรับคืน โดยเลือกจากรายการเบิกที่ค้างอยู่ (พร้อมใช้งาน หรือ ชำรุด) | งานผู้ดูแลระบบ ข้อมูลหลัก การนำเข้า |

เมื่อบันทึกขณะออฟไลน์ จะขึ้นว่า **"บันทึกในเครื่องแล้ว — ยังไม่ได้ส่งเข้าระบบ"** หมายความว่ายังไม่ถือว่าเครื่องถูกเบิก/รับคืนในระบบกลางจนกว่าจะส่งสำเร็จ ผู้อื่นที่ดูระบบกลางจึงยังไม่เห็นรายการนี้

## 3. ป้ายสถานะและจำนวนรายการค้าง

แถบด้านบนแสดงป้าย:

| ป้าย | ความหมาย | ท่านต้องทำ |
|---|---|---|
| **เซิร์ฟเวอร์ไม่พร้อม — ทำงานแบบออฟไลน์** | เครื่องนี้เชื่อมต่อเซิร์ฟเวอร์ไม่ได้ | ทำงานต่อได้ตามหัวข้อ 2 |
| **รอส่ง N รายการ** | มี N รายการของท่านที่บันทึกแล้วแต่ยังไม่ถึงเซิร์ฟเวอร์ | เปิดแอปค้างไว้ในที่ที่มีสัญญาณ ระบบส่งเอง (ระบบส่งเฉพาะตอนเปิดแอปอยู่) อย่าล้างข้อมูลเบราว์เซอร์ |
| **รอเจ้าหน้าที่ตรวจสอบ N รายการ** | ส่งถึงเซิร์ฟเวอร์แล้ว แต่ระบบไม่บันทึกอัตโนมัติ (หัวข้อ 5) | แจ้งผู้ตรวจสอบ ไม่ต้องบันทึกซ้ำ |

ป้ายจะหายเองเมื่อรายการส่งครบ หากตัวเลข "รอส่ง" ไม่ลดลงทั้งที่ออนไลน์แล้ว ให้แจ้งผู้ดูแลระบบ

## 4. คำเตือนข้อมูลเก่าเกิน 4 ชั่วโมง

หากเครื่องนี้ **ไม่ได้ซิงค์กับเซิร์ฟเวอร์เกิน 4 ชั่วโมง** ก่อนบันทึกรายการออฟไลน์ครั้งแรกจะมีหน้าเตือน "ข้อมูลในเครื่องอาจล้าสมัย" ต้องกด "รับทราบและดำเนินการต่อ" จึงบันทึกต่อได้ (หลังรับทราบจะมีแถบเตือนค้างบนฟอร์ม) ความหมาย: สถานะเครื่องมือที่เห็นอาจไม่ตรงความจริง เช่น มีผู้อื่นเบิกหรือรับคืนจากอีกเครื่องไปแล้ว ให้ตรวจเครื่องจริงก่อนบันทึก รายการที่บันทึกหลังคำเตือนนี้จะถูกติดธง "ข้อมูลเก่า" ให้ผู้ตรวจสอบพิจารณาก่อน คำเตือนไม่ได้ห้ามการทำงาน

## 5. "รอเจ้าหน้าที่ตรวจสอบ" หมายความว่าอะไร

ระบบกลางไม่บันทึกรายการออฟไลน์เองเมื่อไม่แน่ใจว่าถูกต้อง เช่น เครื่องนั้นถูกเบิกไปแล้วจากอีกเครื่อง มีรายการรับคืนที่ไม่พบรายการเบิกต้นทาง หรือรายการเกิดขึ้นนานกว่า 7 วันก่อนส่งถึงระบบ รายการเหล่านี้ **ยังไม่ถูกบันทึกเป็นการเบิก/รับคืน** และถูกพักไว้ให้เจ้าหน้าที่ตรวจสอบตัดสิน

- ไม่ต้องกรอกซ้ำ เพราะจะทำให้เกิดรายการซ้ำ
- รายการอื่นของเครื่องเดียวกันที่ท่านบันทึกต่อจากรายการนี้ จะถูกพัก (held) จนกว่ารายการแรกถูกตัดสิน
- ผู้ตรวจสอบเข้าหน้า "ตรวจสอบรายการออฟไลน์" (`/sync-review`) ดู `docs/runbooks/PR25E_REVIEWER_GUIDE_TH.md`
- หากฟอร์มแจ้งว่ามีรายการของเครื่องนี้ที่ยังไม่ได้ส่งอยู่แล้ว ระบบจะไม่ให้บันทึกซ้ำ

## 6. เครื่องใช้ร่วมกัน (แท็บเล็ต/PC กลาง)

- รายการที่ยังไม่ได้ส่งผูกกับผู้ใช้ที่บันทึก ควรรอให้ "รอส่ง" เป็น 0 ก่อนออกจากระบบ (ระบบยังไม่เตือนเมื่อออกจากระบบขณะมีรายการค้าง) รายการที่ค้างจะอยู่ในเครื่องรอจนผู้ใช้นั้นกลับมา หรือมีผู้รับช่วงส่งแทน (หัวข้อ 7)
- ห้ามล้างข้อมูลเว็บไซต์/แคชของเบราว์เซอร์ และห้ามใช้โหมดส่วนตัว เพราะรายการที่ยังไม่ได้ส่งจะหายถาวร
- มือถือส่วนตัว: ป้องกันด้วยการล็อกหน้าจอของเครื่อง ระบบไม่มี PIN หรือการเข้ารหัสเพิ่ม
- ในเครื่องเดียวกัน รายการเบิกที่ผู้ใช้อื่นบันทึกไว้แต่ยังไม่ได้ส่ง จะไม่แสดงให้เลือกรับคืน ต้องให้ส่งหรือรับช่วงส่ง (หัวข้อ 7) ก่อน (ดู `docs/KNOWN_LIMITATIONS.md`)

## 7. รับช่วงส่งรายการของผู้อื่น (adopt)

เมื่อเพื่อนร่วมงานบันทึกออฟไลน์แล้วออกไปโดยไม่ได้ส่ง เจ้าหน้าที่ Pool หรือผู้ดูแลระบบอีกคนส่งแทนได้จากเครื่องเดียวกัน:

1. ล็อกอินด้วยบัญชีของท่านเองบนเครื่องนั้น **ขณะออนไลน์**
2. เปิดหน้า "ตรวจสอบรายการออฟไลน์" ส่วน **"รายการค้างของผู้ใช้อื่น"** (ปัจจุบันมีเฉพาะหน้านี้ ไม่มีป้ายบอกที่อื่น)
3. กด "ส่งแทน" ตรวจจำนวนและชื่อผู้บันทึก แล้ว **กรอกรหัสผ่านของท่านอีกครั้ง** (เซิร์ฟเวอร์ยอมรับเฉพาะการล็อกอินด้วยรหัสผ่านภายใน 15 นาที หากหมดเวลาให้ล็อกอินใหม่)
4. ผลลัพธ์: ผู้บันทึกเดิมยังเป็นผู้บันทึก ท่านถูกบันทึกเป็น **ผู้ส่ง** และมี audit ทุกรายการ

ส่งแทนได้เฉพาะรายการที่ "รอส่ง" รายการที่รอตรวจสอบ ถูกปฏิเสธ หรือถูกพักส่งแทนไม่ได้ ควรตรวจกับเจ้าของรายการหรือหัวหน้างานก่อนส่งแทน

## 8. อัปเดตแอปอย่างปลอดภัย

เมื่อมีเวอร์ชันใหม่ จะมีประกาศ **"มีเวอร์ชันใหม่"** ให้กดอัปเดตเอง แอปไม่รีโหลดเองระหว่างทำงาน

- อัปเดตเมื่อ **"รอส่ง" เป็น 0** และไม่มีฟอร์มค้างอยู่ ระบบไม่ยอมรีโหลดหากยังมีรายการค้าง (ของผู้ใช้ใดก็ตามบนเครื่อง) หรือฟอร์มยังไม่ได้บันทึก
- หากขึ้นว่าต้องอัปเดต (เวอร์ชันแอปเก่าเกินไปสำหรับเซิร์ฟเวอร์) ให้รีโหลดแอป รายการที่ค้างไม่หายและจะถูกส่งหลังรีโหลด
- ห้ามถอนการติดตั้งแอป ล้างข้อมูลเว็บไซต์ หรือรีเซ็ตเบราว์เซอร์ขณะมีรายการค้าง
