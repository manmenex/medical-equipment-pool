assignments should use the vendor-neutral **Implementation task** template in
[`tasks/README.md`](tasks/README.md).

the Draft Pull Request workflow are defined in
[`../PROJECT_PLAYBOOK.md`](../PROJECT_PLAYBOOK.md). Roadmap work must also read
the assigned section of
[`../audits/04-consolidated-implementation-plan.md`](../audits/04-consolidated-implementation-plan.md).
